Soul Searching은 기기에 저장된 음악을 감상할 수 있는 완벽하고 강력하며 자유롭게 맞춤 설정할 수 있는 음악 앱입니다.

완벽한 기능:
- 플레이리스트 및 컬렉션 만들기
- 여러 재생 대기열 지원
- 재생 대기열 관리(재생 모드, 추가, 삭제 등)
- 빠른 액세스
- 재생 통계(월별, 연도별, 전체)
- 싱크 가사(오디오 파일 또는 외부 소스에서 가져오기)
- 앨범, 아티스트, 노래 편집(오디오 파일 메타데이터에 저장)
- 한 노래에 여러 아티스트 지원
- 검색 및 정렬
- 폴더 관리
- 플레이어 볼륨 조절
- Android Auto 지원

뛰어난 성능:
- 노래가 아무리 많아도 부드럽게 작동
- 최적화된 로직으로 복잡한 작업도 빠르게 처리

나만의 스타일:
- 다양한 기본 색상 테마
- 어두운 테마 또는 밝은 테마 강제 적용 옵션
- 현재 재생 중인 노래의 앨범 커버 색상에 맞춘 다이내믹 테마
- 화면별로 다이내믹 테마 적용 방식을 맞춤 설정
- 다이내믹 테마 생성에 사용할 기준 색상 선택
- 플레이어 맞춤 설정(스와이프로 노래 변경, 최소화된 플레이어에 진행 상태 표시 등)
- 홈 화면 맞춤 설정(시작 시 열 탭, 표시할 탭, 표시 스타일 등)

클라우드 지원:
참고: Cloudy는 최근에 도입되었으며 아직 알파 단계입니다.

Cloudy를 사용하면 Soul Searching 전용으로 만들어진 자체 호스팅 클라우드에 노래를 저장할 수 있습니다!
데스크톱, 웹, Android 등 여러 플랫폼에서 노래에 접근하세요.
